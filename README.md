# Verve HRMS

Unified Enterprise Management Platform.

## Overview
Verve HRMS is a centralized ecosystem integrating
multiple internal business applications into one platform.

## Modules
- Verve Interview
- Verve Attendance
- Employee Management
- Monthly Performance Reviews
- Leave Management
- Payroll Management
- Task Management
- Meeting Management
- Analytics and Reporting

## Core Capabilities
- Centralized Authentication
- Role-Based Access Control
- Modular Architecture
- Centralized Dashboard
- Integrated Applications
